<task type="auto">
  <name>Task 1: Create arkit_deltas.py — delta extraction and serialization module</name>
  <files>lam/export/arkit_deltas.py</files>
  <action>
Create a new module `lam/export/arkit_deltas.py` with three functions:

1. `extract_arkit_deltas(flame_model, mapping_path) -> (Tensor[52, V, 3], int)`:
   - Access `flame_model.shapedirs_up` (registered buffer, already on GPU)
   - Slice expression portion: `[:, :, n_shape_params:n_shape_params+n_expr_params]` — use model attributes, NOT hardcoded indices. Do NOT use `[:, :, n_shape_params:]` because teeth_bs_flag may add 4 extra dims at the end.
   - Load mapping matrix [52, 100] from `mapping_path` using existing `load_mapping()` from `arkit_flame_mapping.py`
   - Compute all 52 deltas via: `torch.einsum("al,vkl->avk", M_tensor, shapedirs_expr)`
   - Return (deltas, vertex_count)

2. `serialize_arkit_deltas(arkit_deltas, output_path) -> (int, int)`:
   - Permute to Gaussian-major: [V, 52, 3]
   - Pad xyz to vec4 with zero w: [V, 52, 4]
   - Convert to fp16: `.half()`
   - Write raw bytes little-endian to output_path
   - Return (vertex_count, channel_count)

3. `generate_manifest(vertex_count, output_path, arkit_names=None)`:
   - Import ARKIT_BLENDSHAPE_NAMES from arkit_flame_mapping.py
   - Write JSON manifest with: version=2, format="arkit", channel_count=52, channel_names, gaussian_count, delta_types=["position"], precision="fp16", layout="gaussian_major_vec4"
   - Include bone_bindings: jawOpen -> jaw bone axis_angle [0.35, 0, 0], jawForward -> jaw [0, 0, 0.05]
   - Include jawLeft/jawRight bone bindings with y-axis rotation

AVOID: Using animation_forward (nonlinear composition errors). Using shapedirs_up full slice without checking teeth_bs. Hardcoding vertex count to 20000.
  </action>
