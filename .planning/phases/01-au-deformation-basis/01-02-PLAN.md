  <name>Task 1: Create delta visualization script with per-blendshape renders</name>
  <files>tools/visualize_deltas.py</files>
  <action>
Create `tools/visualize_deltas.py` that:

1. Loads FlameHeadSubdivided model (same pattern as test script from plan 01-01)
2. Extracts 52 ARKit deltas using `extract_arkit_deltas()`
3. Gets rest-pose vertex positions: `flame_model.v_template_up` + identity shape contribution
4. For each of the 52 ARKit blendshapes at intensity 1.0:
   - Computes deformed positions: `rest_verts + delta[i]`
   - Saves a simple 3D render (matplotlib 3D scatter or trimesh render) to `output/deltas/{blendshape_name}.png`
   - Also saves the rest pose for comparison: `output/deltas/rest_pose.png`
5. For composition tests, render these combinations:
   - mouthSmileLeft + mouthSmileRight (bilateral smile)
   - jawOpen + mouthSmileLeft + mouthSmileRight (open-mouth smile)
   - eyeBlinkLeft + eyeBlinkRight (both eyes closed)
   - browInnerUp + mouthFrownLeft + mouthFrownRight (sad expression)
   - Save to `output/deltas/composition_{name}.png`
6. Prints a summary table: blendshape name, max displacement (mm), affected region (estimated from which vertices move most)

Use matplotlib 3D scatter plot with faces_up for mesh rendering if trimesh is available, otherwise point cloud scatter. Color by displacement magnitude (blue=rest, red=max displacement).

AVOID: Importing the full LAM model or running inference. Only need FLAME model for vertex positions and shapedirs.
